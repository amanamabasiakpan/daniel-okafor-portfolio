# Daniel Okafor — Portfolio Template

A premium, recruiter-first personal portfolio template for project managers and operations professionals. Designed to be customized and resold.

## Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Centralized content in `src/data/profile.ts`

## Customize

Edit `src/data/profile.ts` to replace name, title, bio, contact, experience, projects, skills, certifications, and testimonials.

Theme colors live in `src/app/globals.css` (`:root` and `.dark`).

Replace `public/resume.pdf` with a real resume if needed. An online resume view lives at `/resume`.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

All demo content is fictional.
